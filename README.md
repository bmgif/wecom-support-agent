# WeCom Support Agent

[简体中文](README.zh-CN.md)

Open-source customer support MVP for WeChat Customer Service (WeCom),
powered by Hermes Agent.

## Planned MVP

- Answer questions using a published knowledge base.
- Let customers sign in to look up their own orders.
- Hand off return and exchange requests and complaints to human agents.

**Status:** Early development. The first milestone is receiving a test message
from WeChat Customer Service and handing the conversation to a human agent.
